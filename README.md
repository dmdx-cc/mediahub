# 全能影库 · MediaHub

把「媒体服务器搭建 + 在线播放通道 + 元数据刮削 + 封面处理」收敛成一个按钮的跨平台工具。

- **Windows**：双击启动，浏览器里操作
- **Docker**：一条 `docker run` 起服务
- **飞牛 fnOS**：`.fpk` 包手动安装

> 项目处于开发中，暂不提供源码。当前仓库仅用于发布说明与版本更新。

---

## 它解决什么问题

自己搭一套能顺畅使用的私人媒体库，通常会卡在这几步：

1. 媒体服务器装完不会配，媒体库建错、分类混乱
2. 想看在线内容，得自己写 `.strm`、自己解决跨域与防盗链
3. 元数据刮不下来，演员、类型、厂商一片空白
4. 封面取到的是包装背面的图（带条码、价格、小图网格），观感很差
5. 知道要挂代理，但搞不清**到底哪一段需要代理、哪些流量是可以省的**

全能影库把这五件事收进一个页面：上面一个大按钮，下面六个步骤状态灯，每一步都能单独重跑。

---

## 主流程

| 步骤 | 内容 | 可否跳过 |
|---|---|---|
| 1 | 媒体服务器（Emby） | ✅ 已装则直接复用，不重复安装 |
| 2 | 在线播放通道 | ✅ |
| 3 | 元数据刮削 | ✅ |
| 4 | 媒体库与分类 | ✅ |
| 5 | 封面处理 | ✅ |
| 6 | 端到端自检 | ✅ |

顶部「一键部署」会把六步按依赖顺序跑完；中途失败会停在失败步骤，修好后可从该步继续。

## 环境识别

启动时自动探测，不需要用户手填：

- 操作系统与发行版（Windows / Linux / 飞牛 / 群晖 / 威联通 / Unraid）
- CPU 架构与核心数、可用内存、磁盘余量
- Docker 是否可用、是否有权限
- 端口占用情况（媒体服务器、中继、界面）
- 是否已存在可复用的媒体服务器实例

---

## 关于代理

工具**不代管代理软件**，只明确告知边界：

| 环节 | 是否需要代理 | 说明 |
|---|---|---|
| 播放器 → 本机媒体服务器 | ❌ 不需要 | 局域网直连，不消耗代理流量 |
| 媒体服务器/中继 → 内容源 | ✅ 需要 | 只有这一段走代理 |
| 元数据与封面抓取 | ✅ 需要 | 与上一行共用同一个代理 |

界面上留了代理地址输入框，但不会替你改系统代理设置——代理软件形态太多，自动改配置出问题的概率远高于省下的那点操作。
